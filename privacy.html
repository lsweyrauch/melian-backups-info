Data handling

Privacy policy

Effective November 1, 2026

This policy applies to the private Melian Backups Google Drive integration operated by Lukas Weyrauch. It describes this backup tool, rather than every application in the Melian ecosystem.

Google account information and permissions

The tool uses Google OAuth authorization to access the operator’s selected Drive account. It stores authorization tokens on the operator’s private server so scheduled backups can run. The tool does not request Gmail access or the Google account password.

Using the drive.file scope, it reads and writes files created by or explicitly made available to this application. It reads repository metadata, lists and downloads backup files for checks or recovery, and deletes expired backup data according to retention settings.

Backup contents and use

Backups may contain asset inventory, organizational records, account and authentication information including MFA data, configuration credentials, and private certificate authority material from the operator’s Melian installation. These records are encrypted by restic before upload to Google Drive. Data is used for backup, integrity verification, and disaster recovery.

Google authorization tokens remain on the private server and are not included in backup snapshots. The backup encryption password is held separately from the Google account, with a separate recovery copy maintained by the operator.

Storage and disclosure

Encrypted repository files are stored in the operator’s Google Drive. The tool runs on the operator’s server; rclone and restic are software components used to transfer and encrypt the files. The operator does not sell backup information, use it for advertising, or use Google user data to train generalized artificial intelligence or machine learning models.

Google processes storage and account information under its own applicable policies. The operator may restore records to a controlled recovery environment for verification or recovery.

Retention and deletion

The configured schedule is intended to retain seven daily, four weekly, and six monthly recovery points. Expired snapshots and unneeded repository data are removed during successful maintenance. Google Drive trash and provider retention may affect final deletion.

The operator can stop the schedule and delete repository files from Google Drive. Revoking authorization stops future access but does not itself delete already stored backups.

Control and contact

The account owner can revoke this application’s access through Google Account third-party connections. Contact meliancloud@gmail.com about this integration or its data handling.

This information website

This static site does not include analytics, advertising, tracking scripts, sign-in, or data collection forms. Its hosting provider, GitHub Pages, may process connection information such as IP addresses for operating and securing the service; see GitHub’s privacy statement.

Changes

The operator will update this page and its effective date when the integration’s data practices change.
