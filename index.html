Melian Backups

Melian Backups is a private tool operated by Lukas Weyrauch to store encrypted recovery copies of a privately operated Melian installation in the operator’s Google Drive.

Purpose and Google Drive access

The integration uses restic and rclone to upload, list, read, and remove backup repository files. It requests the drive.file permission, which limits access to files created by or explicitly made available to this application.

Backup contents are encrypted on the operator’s server before upload. The encryption password is managed separately from Google authorization.

Who uses it

This integration is for the operator’s own backup account. This website does not offer public registration, Google sign-in, or access to the backup repository.

Read the privacy policy for information about data handling, retention, and revoking access.
